### Added

- **Hypothetical long/short model portfolio dashboard section (ADR-0012).** Tracks
  two forward-only, dollar-neutral portfolios — one rebalanced weekly, one monthly —
  long the `aggregated-scores-best` preset and short `aggregated-scores-worst`,
  weighted by a joint Min Variance optimizer (`scipy`, an optional `portfolio`
  extra). No backtest, no stored NAV: the weekly cron persists only return rows and
  target weights, and the dashboard compounds them client-side into an index chart
  plus a holdings table. Raw prices are never committed — held in memory and, when
  run locally, cached to a gitignored `results/prices/`.
