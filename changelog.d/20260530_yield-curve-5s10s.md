### Added

- **5s10s US Treasury slope tab in the long-term-context panel (#165).** New `src/data_sources/yield_curve.py` fetches yfinance `^TNX` (10y) + `^FVX` (5y) closes, computes the slope (`tnx − fvx` in percentage points; positive = normal curve, negative = inversion), and merges into per-year history files at `results/yield_curve/YYYY.json`. Daily cron `.github/workflows/yield-curve.yaml` runs at 22:30 UTC (1h after the F&G cron — staggers the `data` branch ref races) and commits via the same verified Git Data API pattern as `fear-greed.yaml`. Dashboard gains a third tab — "5s10s slope" — inside the existing `#fg-tabs` group; the section's `CNN Fear & Greed` heading is dropped and the tabs (now `CNN F&G rolling` / `CNN F&G long-term` / `5s10s slope`) carry their own identity. Tab is lazily rendered on first click — initial paint stays cheap. Boundary policy: yfinance reads `wrap-degrade` per leg; both legs failing → no write rather than a stale row. ADR-0005 Tier-0 classification (keyless yfinance pull, default-on cron, persistable to `data` branch). 10 unit tests (TDD red → green) + 1 `@pytest.mark.network` smoke that pins the unit-shape contract (`^TNX` and `^FVX` ship as percentage points, not decimal).
